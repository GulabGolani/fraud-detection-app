# 🚨 AI-Powered Fraud Detection & Risk Intelligence Platform

🚀 **Live App:** https://aifraud-detection-app.streamlit.app/  
💻 **Source Code:** https://github.com/GulabGolani/fraud-detection-app  

---

## 📌 Overview

This project is a real-time **Fraud Detection & Risk Intelligence Platform** designed to identify suspicious financial transactions using a hybrid approach of **Machine Learning and Rule-Based Risk Scoring**.

It simulates real-world fintech scenarios where detecting fraud quickly and accurately is critical for minimizing financial loss and improving trust.

---

## 🎯 Objectives

- Detect fraudulent transactions in real-time  
- Reduce false positives using hybrid logic (ML + business rules)  
- Provide explainable insights for decision-making  
- Enable monitoring of transaction risk through dashboards  

---

## ⚙️ System Architecture

- **Frontend:** Streamlit (Interactive Dashboard)  
- **Backend:** Python  
- **Machine Learning Model:** Isolation Forest  
- **Risk Engine:** Rule-Based + ML Hybrid  
- **Data Storage:** CSV / Session-based tracking  
- **Visualization:** Plotly  

---

## 🔍 Key Features

### 🧠 Real-Time Fraud Detection
- Analyze transaction inputs (amount, location, device, time)
- Classify transactions into:
  - ✅ Safe  
  - ⚠️ Suspicious  
  - 🚨 Fraud  

---

### 🤖 Hybrid Risk Scoring Engine
- Machine Learning (Isolation Forest) for anomaly detection  
- Rule-based scoring for business logic:
  - High transaction amount  
  - Unusual location  
  - Unknown device  
  - Odd transaction time  

---

### 📊 Interactive Dashboard
- Risk distribution analysis  
- Fraud vs Safe transaction insights  
- Trend analysis for transaction behavior  

---

### 🔎 Explainable AI (XAI)
- Highlights reasons behind flagged transactions:
  - High amount  
  - Unusual behavior  
  - Pattern anomalies  

---

## 📊 Business Impact

- Helps fintech companies **detect fraud early and reduce financial risk**  
- Supports **data-driven decision-making** with risk insights
